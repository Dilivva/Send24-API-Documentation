# Send24 Documentation

Welcome to the official documentation for **Send24** – a lightweight, logistics platform designed for fast and efficient delivery in Nigeria. This repository provides all the technical information and API references required to understand, integrate, and contribute to Send24's ecosystem.

---

## 🚀 Overview

Send24 is a logistics tech platform focused on solving the challenges of last-mile delivery through a novel Hubs model. This documentation breaks down how to integrate our Wordpress plugin.

Key Variants:
- Hub-Door
- Hub-Hub
- Door-Hub
- Door-Hub
